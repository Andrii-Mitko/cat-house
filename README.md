# 🐱 Котодім — Cat House

A responsive cat-themed website built with HTML and CSS.

## 🌐 Live Demo

**[View Cat House Website](https://andrii-mitko.github.io/cat-house/)**

## 📖 About the Project

Cat House is a front-end website dedicated to cats, their behavior, breeds, care, and cultural significance.

The project features a responsive layout, article cards, a blog section, social media links, and a video preview.

## ✨ Features

- Responsive layout for mobile and desktop screens
- Featured article cards with image overlays
- Blog section with images, titles, and descriptions
- Social media section with custom icons
- Video preview section
- Custom typography using the Montserrat font
- CSS Grid layouts and reusable design variables
- Responsive images using the HTML `<picture>` element

## 🛠️ Technologies

- HTML5
- CSS3
- CSS Grid
- Responsive Web Design
- Google Fonts
- JavaScript
- GitHub Pages

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Andrii-Mitko/cat-house.git
   ```

2. Open the project directory.
3. Open `index.html` in your browser.

No build tools or package installation are required for the HTML page.
